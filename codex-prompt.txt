## 7. Fix room scan → 2D floor plan accuracy

Once the current behavior and API contracts are understood, improve the scanning pipeline.

Target architecture:

```text
AR / room photos / measurements
        ↓
extract room boundary and openings
        ↓
extract relative furniture geometry
        ↓
construct proportional 2D model
        ↓
determine whether reliable absolute scale exists
        ↓
if scale is uncertain, ask user for one known dimension
        ↓
calculate scale factor
        ↓
rescale room + openings + furniture consistently
        ↓
validate geometry
        ↓
show editable Check Scan result
```

### Geometry priorities

Prioritize:

* accurate room boundary
* relative wall proportions
* correct opening locations
* correct furniture positions
* correct furniture orientation
* consistent furniture sizing

### Measurement accuracy

Never fabricate precise centimeter measurements if the scan does not provide enough scale information.

If scale confidence is low:

1. generate proportional geometry first
2. clearly mark measurements as estimated
3. ask the user to confirm one known real-world measurement
4. derive a global scale factor
5. rescale the room, openings, and furniture consistently

### Validation

Flag or reject:

* furniture outside room boundaries
* furniture crossing walls
* impossible overlaps
* blocked doors/openings
* invalid dimensions
* inconsistent scale
* impossible geometry
